# お子さんの靴、大丈夫？ 60秒チェック — Version 1

HTML・CSS・JavaScriptだけで動くWebアプリです。インストール、コマンド入力、会員登録は不要です。

## 1. ファイルの役割

| ファイル・フォルダー | 役割 |
| --- | --- |
| index.html | ブラウザで開く入口。ページの基本構造・院名・タイトルを設定します。 |
| style.css | 色、文字の大きさ、余白、ボタン、スマートフォン表示を設定します。 |
| app.js | 質問・選択肢・点数・説明文・URLと、採点・画面切り替えの処理をまとめています。 |
| README.md | この説明書です。メモ帳で読めます。 |
| TEST-RESULTS.md | 制作時の確認内容と確認範囲です。 |
| assets/images/ | 今後追加する写真・解説画像を置きます。 |
| assets/icons/ | 今後追加するアイコン画像を置きます。 |
| assets/videos/ | 今後追加する動画を置きます。 |

フォルダー内の「ここに〜.txt」は案内用です。アプリでは使いません。

## 2. Windowsで開く方法

1. ZIPを使う場合は、ZIPを右クリックして「すべて展開」を選びます。ZIPの中から直接開かないでください。
2. 展開した `shoe-check` フォルダーを開きます。
3. `index.html` をダブルクリックします。
4. Microsoft EdgeやGoogle Chromeでトップ画面が開きます。「チェックをはじめる」を押してください。

コードが文字として表示された場合は、index.htmlを右クリック →「プログラムから開く」→ Microsoft EdgeまたはGoogle Chromeを選びます。

同じフォルダーにindex.html、style.css、app.jsを置いたまま使ってください。移動するときはshoe-checkフォルダーごと移します。インターネットがなくても動きます。URLを設定した外部リンクへの移動にはインターネット接続が必要です。

回答はブラウザのメモリ内だけに保持します。アプリ内の「戻る」では消えませんが、再読み込み・タブを閉じる・「最初から再チェック」で消えます。ブラウザ自体の戻るボタンではなく、画面内の「戻る」を使ってください。

## 編集する前に

shoe-checkフォルダーをコピーしてバックアップします。編集するファイルを右クリック →「プログラムから開く」→「メモ帳」で開きます。Ctrl + Fで下記の文字を検索できます。保存はCtrl + S。保存後、ブラウザでCtrl + F5を押して読み込み直します。UTF-8で保存し、ファイル名の末尾に `.txt` を付けないでください。

## 3. 質問文を変える場所

app.jsで `const questions` を検索します。q1が1問目、q2が2問目です。

```js
question: "つま先に余裕はありますか？", // 質問文
helpText: "靴を履いて立った状態で確認してください。", // 補足
```

`question` の引用符の中を変更します。選択肢は `answers` 内の `text` を変更します。

```js
{id:"B", text:"5mmくらい", score:1}
```

`id`（q1、A、Bなど）は判定に使うので変更しません。引用符、カンマ、括弧も残してください。文章内に改行を入れる場合は `\n` と書きます。

トップ画面の説明は `renderStart`、結果文は `resultBands`、個別アドバイスは `advice`、今日の行動文は `actionPriority`、解説は `guides` にあります。

「正しいチェック方法を見る」のカードは、`guides` 内の `title` が見出し、`text` が導入文、`steps` が番号付きの手順（2〜4件）、`note` が最後の注意点です。サイズの3項目は、それぞれ別の確認方法です。手順を変更するときは `steps` の各引用符の中を編集してください。

## 4. 点数を変える場所

app.jsのquestions内、各選択肢の `score` を変更します。

```js
{id:"B", text:"5mmくらい", score:1} // この1が点数です
```

Version 1では0・1・2の範囲で変更してください。Q1〜Q6のみ合計され、Q7のscoreは合計に使いません。Q7はB〜Fのどれかを選ぶとpainFlagがtrueになります。

判定の境界は `resultBands` の `max:2`、`max:5`、`max:12` です。0〜2点、3〜5点、6〜12点に分かれます。0点は○、1点は△、2点は要チェックです。3点以上の配点や質問追加を行う場合は、最大点表示・項目評価・アドバイス・優先順位・テストも合わせて見直す必要があります。

## 5. CTAのリンク先URLを変える場所

app.jsの先頭にある2つの設定で管理します。それぞれのURLは、ここ1か所を変更するだけで差し替えられます。

```js
const LINE_CTA_URL = "https://lin.ee/VAjpcR3";
const SEMINAR_CTA_URL = "https://tsumadaseikotsuin.jp/?p=7158#i-4";
```

`LINE_CTA_URL` は「院長公式LINEで相談する」、`SEMINAR_CTA_URL` は「無料の足・靴セミナーを見る」のリンク先です。引用符の中を新しいURLに置き換えて保存します。空欄にすると、そのボタンだけ無効になり準備中の案内が表示されます。

結果画面の最下部で、LINEは緑のメインボタン、無料セミナーは白地に緑の枠のサブボタンとして表示します。どちらも同じタブで移動します。LINEへの移動後は、端末の設定に応じてLINEアプリが開くことがあります。チェックの回答がリンクに付加されることはありません。

## 6. 画像・動画を追加する場所

まずファイルを次の場所にコピーします。半角英数字のファイル名がおすすめです。

- 写真：assets/images/size-check.jpg
- 動画：assets/videos/size-check.mp4
- アイコン：assets/icons/内（表示したい場所のHTMLにも追加が必要です）

app.jsで `const guides` を検索します。追加したい解説カードの次の空欄を変更します。

```js
image: "assets/images/size-check.jpg",
imageAlt: "靴を履いてつま先の余裕を確認している様子",
video: "assets/videos/size-check.mp4",
link: ""
```

画像だけならvideoは空欄のまま、動画だけならimageは空欄のままで構いません。imageAltには画像の内容を文章で説明します。結果の「正しいチェック方法を見る」を押すと追加した内容が表示されます。動画は自動再生せず再生ボタンで操作します。動画の説明はカードのtextにも記載してください。

別ページや外部動画ページへ移動させる場合は、`link` にURLを入れると「詳しい解説を見る」が表示されます。YouTubeのページURLはvideoではなくlinkに入れてください。ローカルの画像・動画なら、外部サービスへの通信なしで表示できます。

## Version 1での補足

- Q7の「特にない」は症状と同時には選べません。他の症状同士は複数選択できます。
- 今日からできることは、痛み → サイズ → かかとのフィット → 靴紐 → 曲がる位置 → ヒールカウンター → シャンクの順に最大3件です。
- 該当項目が0件のときも、定期確認の案内を1件表示します。
- 回答データを送信する処理、アクセス解析、Cookie、データベース、ログインはありません。
- 医療診断や競技別判定は行いません。
- インターネット上への公開は行っていません。Windowsでファイルを開いて使える完成版です。

## 最終調整：結果と詳しい確認方法

合計点は画面に表示せず、内部の総合判定だけに使用します。詳しい確認方法は、見出しを押すと開き、もう一度押すと閉じる形式です。最初は5項目とも閉じています。

表示順は要チェック→△→○。同じ評価ならサイズ→曲がる位置→シャンク→ヒールカウンター→靴紐・かかとの順です。靴紐・かかとはQ2とQ6の高い方を使います。要チェックだけに「今回ここを確認」を表示します。app.jsのguides内のlabelが折りたたみ見出し、questionIdsが対応する質問、prioritizeGuidesが表示順の処理です。
